**VERSIONING SEMANTIQUE **
V**MAJEUR**.**MINEUR**.**CORRECTIF**
**Le premier chiffre — MAJEUR**
Changement radical. Refonte complète, nouveau design, nouvelle structure. Les anciennes URLs peuvent ne plus fonctionner.
Exemple : tu passes d'une landing page à un site multi-pages → V2.0.0
**Le deuxième chiffre — MINEUR**
Nouvelle fonctionnalité ajoutée, sans casser ce qui existe.
Exemple : tu ajoutes le formulaire EmailJS → V1.1.0
**Le troisième chiffre — CORRECTIF**
Bug fix, petite correction, ajustement visuel.
Exemple : tu corriges la casse Index.html → V1.0.1
